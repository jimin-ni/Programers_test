#### **😅개선점**

### **다른 풀이**

```js
// k번째 사람이 받는 사람의 배열 인덱스
const index = (2 * (k - 1)) % numbers.length;
return numbers[index];
```

#### **📝해설**
- 인덱스가 몇 칸씩 움직이는지 계산한 공식으로 풀이할 수 있다.
1. 1번째 사람(시작 위치) <br>
   움직인 칸 수: 0이다. `(1 - 1 ) * 2 = 0` <br>
2. 2번째 사람이 받는다 = 공을 1번 던진다 <br>
   움직인 칸 수: 2이다. `(2 - 1) * 2 = 2` <br>
3. 3번째 사람이 받는다 = 공을 2번 던진다 <br>
   움직인 칸 수: 4이다. `(3 - 1) * 2 = 4` <br>


### **🔖정리**

1. k - 1: 공을 던지는 횟수 (첫 번째 사람은 가만히 서서 시작부터 받으므로, $k$번째 사람이 받으려면 총 $k-1$번 던져야 합니다.)
2. * 2: 공을 한 번 던질 때마다 건너뛰는 칸 수 (오른쪽으로 한 명을 건너뛰기 때문에 매번 인덱스가 2씩 증가합니다.)

즉, (k - 1) * 2는 "시작 위치에서 출발해, 공을 총 몇 번 던졌으며, 던질 때마다 2칸씩 총 몇 칸을 이동해야 하는지"를 한 번에 구하는 수식입니다!
